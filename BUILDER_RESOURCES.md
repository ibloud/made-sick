# Builder resources

Use these official project channels for product-specific technical questions. Made Sick does not speak for Germ Network or Streamplace, and their documentation remains authoritative for their services.

Links were reviewed on September 6, 2026. Discord invitations can expire; if one stops working, return to the project's official site or documentation rather than trusting an unofficial replacement.

## Germ Network

### Start here

- Product site: https://www.germnetwork.com/
- Using Germ DM: https://www.germnetwork.com/using-germ-dm
- AT Protocol integration overview: https://www.germnetwork.com/blog/integrating-germ-atproto
- Official GitHub organization: https://github.com/germ-network
- Official support Discord, linked from the current Germ DM guide: https://discord.gg/tefK6VR8GS

### Relevant repositories

- Communicator Protocol: https://github.com/germ-network/autonomous-comm-protocol
- Germ AT Protocol lexicons: https://github.com/germ-network/lexicon
- AT Protocol OAuth for Swift: https://github.com/germ-network/AtprotoOAuth
- AT Protocol client for Swift: https://github.com/germ-network/AtprotoClient

The Germ organization contains additional cryptography and client libraries. Builders should choose them through Germ's current documentation or maintainers rather than assuming every public repository is required. `ATProtoLiteClient` and `ATProtoKit` are archived and should not be presented as current integration starting points.

### Made Sick boundary

Germ is the optional private-message route. Do not copy private messages into profiles, use DMs as a clinical-support pathway, promise total metadata anonymity, or enable contact without the creator's consent.

## Creative career learning

### Explore The Futur

Made Sick is Dominique Devereaux’s independent expression of the spirit behind Chris Do’s **1 Billion Mission**: helping more people make a living doing what they love.

Creators looking for practical education about creativity, business, personal branding, pricing, and building a sustainable creative career can visit:

- The Futur: https://thefutur.com/

Made Sick is an independent project and is not affiliated with or endorsed by Chris Do or The Futur. This is an optional external learning resource. It is separate from PIXIE’s health features and must never be used to gate access, create urgency, enroll someone automatically, or suggest that income is a condition of recovery.
