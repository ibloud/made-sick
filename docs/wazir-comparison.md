2. Keep each first response without manual edits; record prompt text, date, settings and credits. Do not retry one tool more often than the other.
3. Assess against the brief: title/URL accuracy; preservation of meaning; invented details; readability/crop instructions; required editing. Report concrete differences before any preference.
4. For image comparisons, use the same generator, dimensions and settings. Repeated paired generations are needed before making claims about reliability; one pair is only an example.
5. Let Dominique assess anonymized A/B outputs before revealing tool identity where practical. An assistant evaluating its own output cannot make the test completely free of bias.
